# B2B Marketing Case Study: Endava Romania

Coursework project developed for the **Marketing** course.

## Overview
This repository contains a comprehensive case study analyzing the marketing strategies, market positioning, and corporate environment of IT consulting firm **Endava Romania**.

## Covered Topics
1. **Company Profile & Financials:** Core capabilities in Digital Transformation, global footprint, and financial performance, turnover, net profit, headcount.
2. **Environmental Analysis:**
   * *Macro-environment:* Technological, economic, social, and regulatory dynamics, including NYSE 20-F annual filings.
   * *Micro-environment:* Key B2B market verticals, Payments, TMT, Retail, Healthcare and domestic competition, Luxoft, SoftServe, Stefanini.
3. **Market Strategy & SWOT Matrix:**
   * STP approach, Segmentation, Targeting, and high-tier Positioning.
   * Internal strengths/weaknesses matched against external opportunities/threats in the local tech ecosystem.
4. **The Marketing Mix - 4Ps:**
   * *Product:* Bespoke software development and technical strategy.
   * *Price:* Skimming pricing strategy targeting enterprise budgets.
   * *Place / Distribution:* Direct B2B service delivery via cloud infrastructure and 10 regional development hubs.
   * *Promotion:* Technical PR, investor relations, industry events, and campus employer branding.
