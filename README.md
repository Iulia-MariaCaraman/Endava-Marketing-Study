# Analiză de Marketing: Endava România

Proiect universitar realizat pentru disciplina **Marketing**.
## Despre proiect
Acest repository conține un studiu de caz complet asupra activității de marketing și a poziționării pe piață a companiei IT **Endava România**.

Am analizat modul în care o multinațională din zona de transformare digitală își gestionează imaginea, atragerea clienților mari B2B și recrutarea forței de muncă pe piața locală.

## Teme abordate
1. **Profilul organizației:** Istoric, domeniu de activitate (Digital Transformation) și principalii indicatori economici - cifră de afaceri, profit net, număr de angajați.
2. **Mediul de marketing:**
   * *Macromediu:* Factorii tehnologici, economici, socio-culturali și juridici.
   * *Micromediu:* Segmentele de clienți B2B - Payments, TMT, Retail, Healthcare, și principalii competitori din România - Luxoft, SoftServe, Stefanini.
3. **Strategia de piață & Analiza SWOT:**
   * Segmentare, țintire și poziționare pe servicii premium.
   * Matricea SWOT (puncte tari, puncte slabe, oportunități și amenințări în IT).
4. **Mixul de Marketing - Cei 4P:**
   * *Produs:* Servicii de dezvoltare software customizat și consultanță.
   * *Preț:* Strategia de skimming, tarife premium justificate prin expertiză.
   * *Distribuție:* Canale directe, livrare digitală prin cloud și centre de livrare locale.
   * *Promovare:* Relații publice, conferințe de tehnologie și un accent puternic pe *employer branding* pentru atragerea tinerilor din universități.
